# Executable validation and its limits

CI builds the application and runs the test suite against PostgreSQL 17 using a restricted runtime role. The browser job migrates/provisions the database, builds API/web, creates isolated users/tenants, then runs four Playwright scenarios against the real API, worker and Next server. Reports, screenshots and failure traces are artifacts. Local Chromium download failed, so a browser pass is not claimed until the CI job completes.

Android CI builds both the actual unsigned driver application and an isolated diagnostics application. Only the diagnostics package receives a throwaway test signature for emulator installation. The API 36 emulator test checks native SQLCipher wrong-key rejection, persisted photos, queue recovery and a force-stop/restart. This does not replace physical device/offline/OS-matrix UAT or an owner-signed production AAB. The raw node-forge advisory audit remains a separate failing job and artifact; exact patch and native/crypto results require independent review. No production signing credential is embedded.

`node scripts/recovery-rehearsal.mjs` is an executable CI rehearsal. It requires `RECOVERY_DRILL_EXECUTE=isolated-fixtures` and a localhost `RECOVERY_DRILL_DATABASE_URL` whose database name contains `test`. It creates uniquely named fixture databases, runs migrations, backs up PostgreSQL and a file-object fixture, removes the source fixture file, restores into an empty database, verifies counts/version references/object SHA-256, and performs a read through the restricted application database adapter. It drops only the databases it created. The result JSON records measured backup/restore/total seconds and states that cloud S3/PITR, production RPO and acceptance workflow replay were not verified. CI uses PostgreSQL 17 client tools from the official container through `POSTGRES_CLIENT_IMAGE=postgres:17-alpine`; operators may use matching installed client binaries instead. No production recovery timing has been measured in this session.

The standalone backup tool requires explicit `cargoorbit_operator` membership. It uses a consistent exported snapshot and RLS-enabled batched INSERT archives, because managed database owners cannot bypass forced row policies. Restore creates the named NOLOGIN groups and grants operator membership only to the restoring owner. Database backup alone is incomplete until every registered evidence, packet and completed export object/version is independently copied and reconciled.

`node scripts/load-test.mjs` prints a dry-run plan. Use `--execute` to run a bounded GET workload; external hosts require HTTPS and a meaningful `LOAD_AUTHORIZATION_REFERENCE`. Settings include `LOAD_BASE_URL`, `LOAD_PATHS_JSON` (JSON array), `LOAD_CONCURRENCY`, `LOAD_DURATION_SECONDS`, `LOAD_MAX_REQUESTS`, `LOAD_REQUESTS_PER_SECOND`, `LOAD_TIMEOUT_MS`, optional `LOAD_ACCESS_TOKEN`, `LOAD_P95_TARGET_MS`, `LOAD_ERROR_RATE_TARGET`, and `LOAD_REPORT`. The tool refuses embedded credentials/redirects and caps response size, request count, duration and concurrency. Reports contain actual latency percentiles, errors, rate and bytes. Acceptance is null without approved thresholds. Unit tests exercise a real local HTTP server with deliberate failures; those numbers are not production capacity evidence.

Bounded entity pages use tenant/filter-bound keyset cursors with at most 500 results. Pages are not snapshot isolation across requests: changes may move records between filters. Usage counters represent registered records, serialized metadata bytes and registered object sizes; they do not estimate physical database/bucket billing or deduplicate repeated object references. Only migration/operator authority may provision contract usage ceilings; tenant owners cannot increase their signed commercial ceiling.

`release-readiness.mjs` validates configuration and named evidence references on the exact commit. It does not itself certify external tests. A `reviewed_mitigation` mobile security record is explicitly separate from a clean raw audit and requires an independent reviewer, exact pinned source/file hashes, Node-only scope and regression evidence. Blank or pending evidence fails closed.
